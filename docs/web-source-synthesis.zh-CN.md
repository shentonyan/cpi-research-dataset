# PI / CPI 外部网页线索：概念梳理与入库规则

本页把用户提供的网页转成可追溯的补充线索。它们不属于本库已经筛选的学术语料，也不改变 1,071 条记录、各主题计数或检索截点。来源状态、访问日期、证据角色与使用限制见 [`data/external_source_register.json`](../data/external_source_register.json)。

## 可从可读网页提取的研究线索

可读的行业文章对 PI 的共同描述是：通过标准化封装、开放接口/协议与物流节点，把原本分散的物流资源连接为可协同的实体网络。它们也提醒，物联网解决物品与信息的连接，PI的研究对象还包括实体物流网络的组织与运行。[搜狐：全球PI发展分析](https://www.sohu.com/a/867419902_757817) 的这些内容适合作为检索词和概念核对入口，不能代替PI领域的原始研究综述。

对 CPI，团队/行业文章与区域综述强调在 PI 物理网络上连接数字表征、信息互操作、网络服务、调度和执行反馈。[逗号科技文章](https://www.smartcomma.com/487/) 和 [大湾区PI/CPI综述](https://www.sohu.com/a/1048409872_649545) 提供了可供全文核对的方向：数字化与对象身份、节点/网络配置、跨节点服务、协作机制，以及跨境、多式联运、制造物流等场景。这里是对网页内容的归纳，不代表这些维度已构成统一且无争议的CPI标准定义。

## 建议用于后续精读的编码框架

将每篇文献的研究贡献编码到可观察的问题，而不是只按“数字孪生”“智能物流”等宽泛标签归类。可在现有 `research_extraction_template.csv` 中逐篇补充；只有全文证据明确时才填写。

| 分析维度 | 精读时记录的对象 | 证据问题 |
|---|---|---|
| 物理网络 | 货物/模块、节点、运输方式、容量与时间窗 | 是否建模真实装卸、转运、库存或跨境约束？ |
| 数字化与身份 | 货物、节点、资源的标识、状态采集、数字映射 | 数据如何产生、更新、定位和验证？ |
| 互操作与协议 | 数据格式、接口、寻址、路由、计划及执行协议 | 哪些主体实际互通？延迟、缺失或不兼容如何处理？ |
| 网络服务与配置 | 路由、匹配、容量共享、服务组合、资源分配 | 决策变量、目标、约束和基线是什么？ |
| 协作与治理 | 激励、定价、隐私、信任、责任和收益分配 | 参与方有什么私有信息？机制性质在什么假设下成立？ |
| 执行与反馈 | 计划—执行—状态更新—重调度闭环 | 是否有真实运行、实验或可复现仿真证据？ |
| 应用场景 | 跨境物流、园区、港口、多式联运、制造及建筑模块 | 场景约束是否进入模型，还是只出现在动机描述中？ |

建议把以上维度视为**候选编码框架**，而不是预设CPI必须具备的正式层级。对于每项结果，同时标注证据形态：形式分析/证明、仿真、实验室或试点、真实运营观测、真实运营干预；不可相互替代。

## 来源质量和待核事项

1. 用户给出的六个入口中，三篇本次可读取；知乎、澎湃页面和百度百科在本次抓取中无法读取。不可读取不等于内容错误，也不能据链接或搜索片段推断正文。
2. 可读页面主要是行业评论、企业团队阐释和二手概述。它们提供术语与项目线索，不作为学术文献、同行评审状态、项目成效或研究空白的独立证据。
3. 大湾区文章提到的 CPI 五层架构及三条研究主线，应优先回查本库已收录的 2025 年系统综述 [Towards cyber-physical internet](https://doi.org/10.1016/j.tre.2025.104051)，再逐项记录原文定义与页码/图表。文章中的地区发展与项目叙述则应回到机构/资助方项目页核实。
4. PI定义、路线图及发展史应优先查找原始学术综述和 ALICE/欧盟项目路线图；媒体文章所述国家实践、企业案例与预期效益未单独核实。

## 纳入语料的规则

- 本次新增网页仅作为“外部来源台账”，不加入文献语料、RIS/BibTeX、引用网络或主题计量。
- 若未来从网页中找到论文、报告或项目，新增记录应指向原始出版者/机构页面，并独立核查题名、作者、日期、DOI、文献类型、版本关系和访问许可。
- 研究结论须附原文位置与证据类型。网页摘要或新闻转述不能填入“研究发现”字段。
- CPI、PI、IoT、数字孪生、网络物理系统等词汇应分别检索和编码，不能仅凭词汇共现认定研究对象相同。
