# 如何用本库开展 CPI 专题研究

## 从核心语境建立阅读顺序

先读框架综述 [Towards cyber-physical internet](https://doi.org/10.1016/j.tre.2025.104051)，列出其定义、五层模型的职责和假设；然后对照 [B2B 路由协议](https://doi.org/10.1016/j.cie.2024.110293) 与 [区域物流基础设施融合](https://doi.org/10.1016/j.aei.2024.102551)，检查抽象如何落到网络、节点、货物和信息更新机制上。

接着按研究兴趣选择分支。这是阅读导航，不是已经完成的文献评价：

| 分支 | 入口 | 精读时要核对的内容 |
|---|---|---|
| 激励、采购与收益分配 | [运输采购拍卖](https://doi.org/10.1016/j.ifacol.2023.10.1160)、[区域定价与分配](https://doi.org/10.1016/j.trc.2024.104714)、[meta-auction](https://doi.org/10.1016/j.tre.2024.103842) | 信息私有性、参与方、支付、效用、激励相容和预算性质分别成立在哪些假设下 |
| 路由与网络协议 | [B2B 路由](https://doi.org/10.1016/j.cie.2024.110293)、[地址解析](https://doi.org/10.1109/JIOT.2025.3562803)、[STAR](https://doi.org/10.1016/j.aei.2025.103830) | 信息更新延迟、路由表容量、路径可行性、物理运输约束和基线是否一致 |
| 能力、拥堵与配置 | [有限数据带宽配置](https://doi.org/10.1016/j.eswa.2024.126003) | “带宽”究竟指处理、存储还是运输能力；估计误差与决策质量如何连接 |
| 碳与多式联运 | [MiC 碳足迹](https://doi.org/10.1016/j.trd.2024.104259)、[海铁港口网关](https://doi.org/10.1016/j.tre.2026.104915) | 排放边界、单位、载荷、等待、空驶、服务水平以及成本权衡 |
| 货物封装与时空约束 | [四维时空封装](https://doi.org/10.1016/j.tre.2026.104843) | 几何、时间和转运条件如何联立，比较是否使用同等计算预算 |
| 数据与可复现性 | [HKU 配套数据记录](https://doi.org/10.25442/hku.32593509) | 文件仍禁运；可先核对描述、版本、许可证与对应研究，不能声称已复现 |

## 用提取表建立自己的证据

打开 `data/processed/research_extraction_template.csv`。每读一篇，填研究问题、决策变量、目标与约束、方法、数据来源、基线、证明/识别条件、限制及证据页码。现在空白是“尚未核实”，不要用题名或 AI 摘要自动补成确定结论。

建议每条主要判断附页码、公式号、表号或原始数据位置。结果分开记录：形式证明、模拟结果、实验室演示、真实运营观察、真实运营干预。某一类证据不能自动支持另一类结论。

外部行业网页提供的 PI/CPI 概念与场景线索、来源质量说明和建议编码维度，见 [网页线索与编码框架](web-source-synthesis.zh-CN.md)。这些网页没有加入论文计数；关键定义和项目事实应回到原始论文及机构记录核实。

## 值得检验的问题，不是已确认的研究空白

1. 信息更新更快时，路由改善会否被处理拥堵、订阅成本或策略性披露抵消？先查已有容量与激励研究，再明确可检验的边际机制。
2. 各节点独立选择路径或共享能力，局部改进在什么条件下提升系统福利？在路由、装载、价格和信息约束共同存在时是否仍成立？
3. 把货物类比成数据包时，哪些性质可迁移，哪些受不可复制、尺寸、能耗、时间窗、装卸和监管约束阻断？
4. 保护商业数据的协议应如何报告性能—隐私—通信量的权衡，而不仅是最短路径或单一成本？
5. 经验验证能否区分协议带来的收益、信息可得性带来的收益和更强求解器带来的收益？

确定选题前，应补充订阅数据库检索、前向引文追踪和核心全文精读。当前语料库中的“没检到”不能作为“没人研究过”的证明。
